v2.0.0 vision: MCP server & AI integration

Early ideas for connecting ProjectLog to the AI tools you already use

⌬

MCP server

A built-in Model Context Protocol server would let compatible AI assistants talk to your ProjectLog workspace in a standard way.

  • Let an assistant read your projects, notes, and roadmap
  • Create projects, add notes, and update progress by request
  • Works with any MCP-compatible client
  • Runs on your machine, started and stopped by you
✦

AI integration

Helpful AI features inside the app, so your project history becomes easier to use and not just to store.

  • Summarize a project's recent activity
  • Turn rough notes into clean Markdown and next steps
  • Suggest roadmap milestones from your goals
  • Ask questions about your own projects

Development plan

Work will move through these stages

PHASE 01
Plan & prioritize

Choose the highest-value improvements and define how each should behave before implementation.

PHASE 02
Build & test

Implement features in small steps, test existing projects and JSON import/export compatibility, and fix regressions.

PHASE 03
Release & listen

Publish the installer and update metadata, document changes, and use feedback to guide the next iteration.
