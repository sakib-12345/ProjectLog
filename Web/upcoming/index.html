ProjectLog v2.0.0

Long-term vision · MCP server and AI integration

LONG-TERM VISION
⌬

MCP server

A built-in Model Context Protocol server would let compatible AI assistants communicate with your ProjectLog workspace in a standard way.

  • Read projects, notes, and roadmap
  • Create projects and add journal entries
  • Update progress through AI requests
  • Connect to MCP-compatible clients
  • Runs locally with user-controlled access
✦

AI integration

Helpful AI features inside the app, so your project history becomes easier to use and not just to store.

  • Summarize recent project activity
  • Turn rough notes into clean Markdown
  • Suggest roadmap milestones
  • Ask questions about your projects
  • Work with external AI assistants

How MCP could work

Development Plan

How ProjectLog features move from idea to release

PHASE 01
Plan & prioritize

Choose the highest-value improvements and define how each should behave before implementation.

PHASE 02
Build & test

Implement features in small steps, test existing projects and JSON import/export compatibility, and fix regressions.

PHASE 03
Release & listen

Publish the installer and update metadata, document changes, and use feedback to guide the next iteration.
